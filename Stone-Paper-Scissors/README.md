# Rock Paper Scissors

A simple Rock Paper Scissors game built with HTML, CSS, and JavaScript.

# About This Project

This is a mini project created while following a JavaScript tutorial to practice basic JavaScript concepts and DOM manipulation.

Players can choose rock, paper, or scissors to play against the computer, which makes a random choice. The game displays the result and keeps track of the scores.

# Technologies Used

- HTML
- CSS
- JavaScript

# What I Practiced

- *DOM Manipulation* – Selecting elements and updating text and styles.
- *Event Listeners* – Handling user interactions with click events.
- *Functions* – Using arrow functions, parameters, and return values.
- *Arrays & forEach()* – Working with arrays and iterating through elements.
- *Conditional Statements* – Using if/else and ternary operators to determine the winner.
- *Random Number Generation* – Using Math.random() and Math.floor() to generate computer choices.
- *Template Literals* – Displaying dynamic game results.
